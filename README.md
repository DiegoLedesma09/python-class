# Python Class

## Descripción
Python Class es un proyecto sencillo desarrollado en Python para servir como punto de partida en clases, ejercicios o pruebas básicas de programación. El objetivo es mostrar una estructura mínima y clara que pueda ampliarse según las necesidades del usuario.

## Características
- Proyecto simple y fácil de entender.
- Compatible con Python 3.
- Incluye un punto de entrada básico para ejecutar el programa.
- Estructura lista para crecer con nuevas funcionalidades.

## Requisitos
- Python 3.10 o superior.
- Pip (opcional, si se agregan dependencias en el futuro).

## Instalación
1. Clona este repositorio.
2. Entra en la carpeta del proyecto:
   ```bash
   cd python-class
   ```
3. Ejecuta el programa con:
   ```bash
   python main.py
   ```

## Uso
El proyecto actual muestra un mensaje de bienvenida por consola:

```bash
Hello from python-class!
```

## Estructura del proyecto
- main.py: punto de entrada principal del programa.
- pyproject.toml: configuración del proyecto y metadatos básicos.
- README.md: documentación del proyecto.
